## 🛠️ Flagship Engineering Systems

### 🎓 01. [Digital School & Exam Platform (Rofaz Academy)](https://github.com/rofazhasan/digital_school)
> **Production AI-Powered Academic Assessment & Diagnostic Ecosystem**  
> *Stack: Next.js 15 (App Router), TypeScript, PostgreSQL, Prisma ORM 6.10, Ollama (Qwen 2.5 / Llama 3.2), TensorFlow.js, SWR*  
> 🔗 **Live Production:** [rofazacademy.dev](https://rofazacademy.dev) • 📂 **Repository:** [rofazhasan/digital_school](https://github.com/rofazhasan/digital_school)

- **Local SLM Diagnostic Pipeline:** Integrated local SLMs running structured JSON schema prompts to detect underlying student conceptual gaps.
- **Deterministic Latency Fallback:** Sub-10ms PostgreSQL-computed fallback ensuring 100% diagnostic reporting availability during peak server traffic.
- **Edge Caching & SWR Sync:** Configured stale-while-revalidate headers reducing database connection loads by up to **70%** during nationwide exam rushes.
- **Multi-Tenant RBAC:** Scalable schema with connection pooling, automated PDF generators for admit cards, tabulation sheets, and question banks.

### 🛡️ 02. [FocusGuard — Distributed Cross-Platform Attention Platform](https://github.com/rofazhasan/FocusGuard)
> **High-Performance Distributed Policy Enforcement & State Streaming Daemon**  
> *Stack: Go 1.22, Docker, WebSockets (Socket.io), Chrome MV3, SQLite, Android VpnService*  
> 📂 **Repository:** [rofazhasan/FocusGuard](https://github.com/rofazhasan/FocusGuard)

- **Distributed Go Daemon:** Coordinates real-time state streaming across desktop, mobile, and browser clients with synchronized screen-time budgets.
- **Zero-Latency Policy Engine:** Compiles behavioral blocking rules into native browser C++ filtering via Chrome MV3 `declarativeNetRequest`, cutting JavaScript execution overhead to 0ms.
- **Local-First Offline Resilience:** Embedded SQLite policy store with delta sync on reconnect; integrated Android UDP DNS sinkhole intercepting restricted domains with RFC 1035 `NXDOMAIN`.

---

### 👁️ 03. [OMRView — In-Browser WebAssembly Computer Vision Engine](https://github.com/rofazhasan/OMRView)
> **Client-Side Real-Time Optical Mark Recognition & Geometric Rectification Engine**  
> *Stack: React 19, TypeScript, Vite, OpenCV.js (WebAssembly)*  
> 📂 **Repository:** [rofazhasan/OMRView](https://github.com/rofazhasan/OMRView)

- **100% Client-Side Processing:** Runs compiled OpenCV C++ inside browser WASM worker threads, eliminating 100% of server image bandwidth and cloud GPU costs.
- **Geometric Homography:** Real-time Canny edge detection and Douglas-Peucker polygon approximation rectifying skewed smartphone captures in **<600ms**.
- **Adaptive Bubble Classifier:** Evaluates pixel intensity histograms against row baseline lighting to accurately classify responses and detect multi-fill collisions.

### 💼 04. [Atlas — macOS Native Financial Operating System](https://github.com/rofazhasan/atlas)

- **Zero-Knowledge Cryptographic Vault:** Hardware-accelerated AES-256 GCM encryption, PBKDF2 key derivation, and Touch ID / `LocalAuthentication` biometric gatekeeping.
- **Apple Vision Offline OCR:** Native on-device document scanner parsing tabular receipts and invoices directly into SwiftData relational entities.
